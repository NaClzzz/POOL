# 第一阶段：前端交互范围

本文维护桌面页面与交互范围；账号、音乐、喜欢、房间、历史及 AI 均已接入真实服务。组件与布局见 [前端设计](../前端设计.md)，数据与接口见 [服务端设计](../服务端设计.md)，业务规则见 [项目概览](../项目概览.md)。

## 页面范围

| 页面 | 当前能力 |
| --- | --- |
| 登录与注册 | 邮箱密码登录、注册直接登录、会话恢复、退出及站内返回路径 |
| 搜索 | 网易云搜索、分页、收藏与个人播放；Bilibili 明确返回未支持 |
| 喜欢 | PostgreSQL 收藏、取消、清空、500 首容量、网易云歌单导入 |
| 个人播放器 | 临时音频资源、播放暂停、定位、音量、顺序／随机、队列拖拽及虚拟列表；跨页不断播 |
| 房间大厅 | 查询、创建、密码加入及跨房切换确认 |
| 听歌房 | 双列搜索／歌单抽屉、歌单导入与拖拽、上下台、轮播、投票、聊天和房主管理 |
| 历史与总结 | 本人历史列表及详情、删除访问记录、共享总结流式生成和保存结果查询 |
| 设置 | 账号资料、昵称与密码修改、本地音量偏好和退出 |

仅面向桌面浏览器；四个导航入口为搜索、喜欢、一起听、设置。沿用 shadcn/ui Base UI、MiSans 字体和 CSS Modules，不增加移动端布局。

## 数据与生命周期

- 普通业务通过统一业务 API 与 Query／Mutation hooks 访问服务；组件只管理展示、表单和界面动作。
- Better Auth Cookie Session 是认证来源，浏览器安全用户投影不作为权限凭证。
- 网易云查询与播放由统一音乐服务适配，播放 URL 按需解析；缺少封面时使用中性色块，不依赖本地曲库、音频或封面文件。
- 喜欢、用户房间歌单、房间历史和总结保存于 PostgreSQL；房间实时状态来自 Socket，页面作用域 Zustand store 不持久化。
- 个人播放器跨页保留；房间页离开立即停音、退房并清理请求、监听与定时器，个人播放不自动恢复。
- 房间总结通过 Vercel AI SDK 流式展示；离页后服务端继续生成，以数据库查询结果为准。
- 音量使用独立本地偏好键 pool:player:volume；密码和认证 token 不写浏览器持久存储。

容量、聊天频率、历史期限及 AI 额度统一以设计文档为准，本文不重复维护参数表。

## 验收路径

1. 注册／登录 → 搜索 → 收藏 → 播放 → 歌单导入。
2. 大厅创建／加入 → 房间搜索加歌 → 上台轮播 → 聊天及投票 → 离页退房。
3. 查看本人历史 → 房间结束后生成总结 → 返回读取已保存结果 → 删除本人历史。
4. 修改账号与音量 → 退出 → 重新登录，检查账号隔离和本地偏好。

个人音频应可播放、暂停、定位和切换，跨页不中断；房间进度只读，不提供暂停。离开房间后不残留音频、连接、订阅或定时器。AI 正文与错误分开，取消、失败和截断不能覆盖已有完整结果；共享总结保存成功后不能重新生成或主动删除。

自动测试中的受控数据与媒体事件不替代多浏览器同步、实际听感和百炼真实调用验收。启动与检查命令见 [README](../../README.md)，应用由用户手动启动。前端与服务端职责入口见 [交付与接入点](01-前端原型完成情况与后端接入准备.md)。
