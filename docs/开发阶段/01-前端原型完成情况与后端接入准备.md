# 前端原型完成情况与后端接入点

当前桌面交互已经覆盖全部页面，账号、网易云个人音乐与 PostgreSQL 喜欢已完成真实接入，交付与验证见 [第三阶段文档](03-网易云音乐与喜欢列表持久化.md)。业务边界以 [项目概览](../项目概览.md)、[服务端设计](../服务端设计.md) 和 [前端设计](../前端设计.md) 为准。

## 当前可复用成果

- 桌面布局、四个导航入口、shadcn/ui Base UI、MiSans 主题、CSS Modules 和反馈组件。
- 真实邮箱密码注册登录、账号展示与修改、会话同步和退出；不再使用浏览器模拟认证。
- 真实网易云匿名搜索、喜欢及歌单导入、虚拟列表、真实个人播放、跨页控制、顺序／随机模式和拖拽队列；Bilibili 仍待接入。
- 房间大厅、模拟加入、上下台、轮播投票、聊天、房主管理，以及搜索／歌单双列抽屉和拖拽排序。
- 房间离页停音与订阅清理、模拟历史权限、总结锁定、固定文本 AI、演示场景及重置。

## 后续真实业务接入点

| 当前位置 | 后续处理 |
| --- | --- |
| src/contracts/domain.ts | 对齐服务端分页、房间歌单 itemId 和播放 DTO，不将 DemoDatabase 直接映射成正式数据库 |
| src/mocks/api.ts | 后续替换大厅、历史及剩余模拟业务；账号、音乐、喜欢已独立，不恢复模拟登录 |
| src/mocks/room-session.ts | 替换为 Socket 通信，保留房间页订阅和退出清理边界 |
| src/stores/player.ts、features/player/ | 个人真实临时资源与错误已接通；后续复用到真实房间音频 |
| src/features/ai/generation-panel.tsx | 保留分段输出界面，接入 Vercel AI SDK 与模型费用控制 |
| localStorage 的 mock 资料 | 按真实用户主键隔离，不自动将旧邮箱键的演示数据写入真实业务数据库 |

现有普通 mock 调用直接返回解包数据，不等于完整 HTTP 契约已经实现。音乐平台、多人同步、业务事务、费用额度及后台清理分别验证，不以真实账号或生产构建通过替代。

## 验证与下一步

当前单元和 mock 测试共 55 项，账号／音乐／数据库集成测试共 21 项，真实源码音源测试 3 项。新账号页面尚待用户启动后完成浏览器验收；第一阶段的布局、拖拽和本地音频浏览器检查不代替真实账号表单验收。检查命令和启动步骤见 [README](../../README.md)。

下一步可按房间通信、房间业务持久化、其他音源和 AI 分别拆分任务。每一步明确替换范围，复用现有页面，不一次将所有 mock 宣称为后端完成。
