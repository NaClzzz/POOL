# 前端交付与服务接入点

桌面页面已覆盖账号、音乐、喜欢、一起听、历史、AI 与设置。本文维护当前前端职责与服务入口，契约以 [项目概览](../项目概览.md)、[服务端设计](../服务端设计.md) 和 [前端设计](../前端设计.md) 为准。

## 交付范围

- 桌面布局、四个导航入口、shadcn/ui Base UI、MiSans 主题、CSS Modules 和统一反馈组件。
- Better Auth 邮箱密码注册登录、账号资料修改、会话同步和退出。
- 网易云匿名搜索、喜欢及歌单导入、虚拟列表、跨页个人播放、顺序／随机模式和拖拽队列。
- 真实大厅与 Socket.IO 房间、上下台轮播、投票、聊天、房主管理及双列歌单抽屉。
- PostgreSQL 房间历史、本人访问记录删除、七天过期和共享总结成功锁定。
- 真实房间总结的流式交互、状态查询与后台完整结果保存。

## 当前接入点

| 位置 | 职责 |
| --- | --- |
| src/contracts/domain.ts、music.ts、room.ts、ai.ts | 页面与服务端共享的曲目、分页、房间及 AI 契约 |
| src/lib/http.ts、api/、api-client.ts | Axios JSON 请求、Query／Mutation hooks、AI 原生流及统一导出 |
| src/features/auth/session-provider.tsx | Cookie 会话投影、账号切换和私有状态清理 |
| src/stores/player.ts、src/features/player/ | 个人队列、跨页音频控制与本地音量偏好 |
| src/features/room/use-room-session.ts | 页面专属 Socket 连接、快照校准、命令确认和卸载 |
| src/features/room/use-room-audio.ts | 房间临时资源、时间锚点、预加载、定位和媒体清理 |
| src/features/ai/、src/lib/api/ai.ts | 房间总结界面、流式生成 hook 与持久状态查询 |
| src/server/、socket-server/、drizzle/ | 服务端权限、业务规则、数据库迁移及独立房间进程 |

Bilibili 尚未接通；主业务均使用服务端权威数据。音乐、账号、房间和 AI 的功能及验收边界分别见第三、第二、第五和第七阶段文档。

## 验证边界

单元测试覆盖请求、业务 hooks、队列、房间会话和音频生命周期、AI 输入及流式完成检查；测试曲目仅位于 tests/fixtures/，不关联本地媒体资源。集成测试使用隔离数据与可控上游，真实音源、百炼调用和多浏览器听感需要独立验收。

检查与启动命令见 [README](../../README.md)，页面验收路径见 [前端交互范围](01-前端交互原型.md)。应用由用户手动启动。
