# 第八阶段：源码集成与容器部署

## 当前交付

- 网易云 API 4.41.1 源码以普通文件存于 `vendor/api-enhanced/`，基准提交、锁文件校验与许可证见 [vendor 说明](../../vendor/README.md)。没有嵌套 Git 或真实环境配置；本地依赖、日志及运行凭据不参与版本管理或镜像上下文。
- `music:dev` 从仓库内音源目录启动，不再读取外部源码路径；音源依赖独立安装，POOL 与上游分别使用各自 package.json、workspace 和锁文件。第三方源码不参与 POOL 类型检查、Lint 或格式化。
- 根 Dockerfile 提供 `web`、`socket`、`migrate` 三个目标；Web 使用 Next standalone，Socket 编译为 JavaScript 并追踪运行依赖，迁移镜像包含已提交 SQL／元数据和 Drizzle runtime。生产不需要 tsx、TypeScript、drizzle-kit，也不会在应用启动时迁移。
- 音源使用上游 Dockerfile 独立构建，仅增加基础镜像参数并调整 `.dockerignore`；没有修改音乐接口或 POOL 适配器业务规则。
- `compose.production.yaml` 单独管理 Web、Socket、音源、PostgreSQL、Redis；migrate 在 tools profile 一次性运行。开发 `compose.yaml` 保持原有端口、卷及启动方式。
- 生产 Web／Socket 宿主机端口只绑定回环；音源、数据库和 Redis 不公开端口，数据使用持久卷。Web／Socket 内部 URL 与浏览器公网 URL 分开配置，不增加 Socket 多实例或 Redis adapter。
- `.env.production.example` 区分运行时密钥和构建时 `NEXT_PUBLIC_SOCKET_URL`；根／音源构建上下文均排除真实 `.env`、本地依赖和生成凭据。
- [Nginx 模板](../../deploy/nginx/pool.conf) 提供宿主机 HTTPS、同域 Socket 轮询／升级、AI SSE 禁止缓冲与超时。完整操作见 [部署指南](../部署指南.md)，含首次部署、迁移、更新、备份恢复。

## 已执行验证

- 生产 Compose（含 tools profile）语法检查通过。
- Web、Socket、音源与迁移四个 Linux 镜像实际构建通过，Web 构建包含 Next 生产编译与 TypeScript 检查。当前网络 Docker Hub 认证超时，音源验证使用可配置镜像源；处理见 [构建环境问题](../issues/容器构建环境与镜像源.md)。
- 音源独立冻结锁安装通过；包与锁文件保持上游原值。
- Web／Socket 镜像文件检查通过：真实 `.env` 与 vendor 源码未进入运行产物；Socket 不带 tsx／esbuild。编译 Socket 的全部静态外部依赖在断网容器中导入成功，没有启动 Socket 服务。
- 迁移脚本和迁移镜像分别在临时隔离数据库连续执行两次通过，得到 4 条迁移与 13 张业务表；测试数据库已清理，没有在开发库执行生产迁移。

- POOL 类型检查、Lint、格式检查与 127 项单元测试通过。

## 验收边界

本阶段没有启动 POOL Web、Socket、音源或生产 Compose 栈。真实域名／证书配置、HTTPS Cookie、WebSocket 连通性、AI SSE 首段、真实音频听感及备份恢复演练仍由部署环境手动验收。现有音乐解析、收藏、房间与 AI 业务规则保持不变。
